This folder stores cached computational outputs generated by the scripts in `../code/`.

Primary cached files:

- `momab_synthetic_experiments/manifest.json`
- `momab_synthetic_experiments/run_cache.npz`
- `momab_synthetic_experiments/trajectory_cache.npz`

Derived files regenerated from the cache:

- `momab_synthetic_experiments/derived_manifest.json`
- `momab_synthetic_experiments/summary.json`
- `momab_synthetic_experiments/trajectory_summary.json`
- `momab_synthetic_experiments/results_table.tex`

The raw cache files are the primary cached outputs. They contain run-level simulation outputs together with a manifest that records the experiment settings, code hashes, and runtime provenance. The plotting CLI in `../code/plot_synthetic_experiments.py` reads these files and regenerates the summary files and table, while `derived_manifest.json` records the plotting-side provenance for those regenerated outputs, including plotting code hashes and the Matplotlib version.

The figures are written to `../plots/`. If older figure files remain in this folder from a previous workflow, they are legacy files rather than the current cached outputs.
